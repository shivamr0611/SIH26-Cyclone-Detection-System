# Satellite Imagery Dataset Directory

Stores multi-spectral satellite imagery files:
- Visible band (VIS) channels
- Thermal Infrared (TIR) channels
- Water Vapor (WV) channels

Supported satellite feeds & public repositories according to SRS Section 6.1:
- INSAT-3D / INSAT-3DR (ISRO MOSDAC)
- GOES-16 / GOES-18 (NOAA)
- Himawari-8/9 (JMA)
- EUMETSAT Meteosat series
- IBTrACS (International Best Track Archive for Climate Stewardship)
